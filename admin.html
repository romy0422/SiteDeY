Connexion GitHub

Cette administration utilise un jeton d'accès personnel à permissions limitées, et non ton mot de passe GitHub. Le jeton reste uniquement en mémoire dans cet onglet.

Crée un jeton « Fine-grained personal access token » sur GitHub, limité à ce dépôt, avec la permission Contents: Read and write et une courte expiration. Ne partage jamais ce jeton. Utilise cette page uniquement sur ton site GitHub Pages en HTTPS.
