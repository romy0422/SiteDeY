Sur GitHub / SiteDeY : ajoute collections.json à la racine du dépôt et tes fichiers images dans le dossier images/. Utilise « Add file → Upload files », puis « Commit changes ». Si collections.json existe déjà, remplace-le uniquement après avoir importé son contenu ici.

Les images ne sont pas téléversées automatiquement. Conserve leurs fichiers originaux sur ton ordinateur.
