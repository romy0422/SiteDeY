Administration sans jeton et sans connexion. Prépare tes collections ici, puis publie manuellement les fichiers dans ton dépôt GitHub. Ton index.html ne sera pas modifié.

1 · Collections

Pour une image choisie ici, le chemin sera automatiquement images/nom-du-fichier. Tu devras aussi envoyer cette image dans le dossier images/ de GitHub.

3 · Enregistrer et publier

Ton brouillon est sauvegardé uniquement dans ce navigateur. Tu peux également importer un ancien fichier collections.json pour reprendre tes collections existantes.

Publication : ouvre ton dépôt SiteDeY. Téléverse collections.json à la racine, et les images dans images/. Attends ensuite la mise à jour de GitHub Pages.
Attention : si tu télécharges le catalogue sans avoir importé ton ancien fichier, il contiendra seulement les collections créées dans cette interface. Garde une copie de ton catalogue actuel avant de le remplacer.
